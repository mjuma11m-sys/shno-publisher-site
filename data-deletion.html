سالفة ستوديو (Salfa Studio) · Data Deletion Instructions

سالفة ستوديو ما تحفظ إلا توكن الربط لحسابات القناة وقائمة أرقام الفيديوهات المنشورة. لحذفها:

  1. إنستغرام: الإعدادات ← الأمان ← التطبيقات والمواقع ← Salfa Studio ← إزالة.
  2. فيسبوك/ميتا: الإعدادات ← التطبيقات والمواقع ← Salfa Studio ← إزالة.
  3. تيك توك: Settings and privacy ← Security ← Manage app permissions ← Salfa Studio ← Remove.
  4. قوقل/يوتيوب: حساب قوقل ← Security ← Third-party access ← Salfa Studio ← Remove access.

بعد الإزالة ينمسح التوكن من أسرار GitHub خلال 7 أيام. ولطلب مسح أي شي ثاني: رسالة لقناة @shnoalsalfa_bh، ونرد خلال 7 أيام.

Data Deletion Instructions

Salfa Studio only stores the OAuth tokens of the channel's own accounts and a list of posted video IDs. To delete them:

  1. Instagram: Settings → Security → Apps and websites → Salfa Studio → Remove.
  2. Facebook/Meta: Settings → Apps and websites → Salfa Studio → Remove.
  3. TikTok: Settings and privacy → Security → Manage app permissions → Salfa Studio → Remove.
  4. Google/YouTube: Google Account → Security → Third-party access → Salfa Studio → Remove access.

After removal, the token is deleted from GitHub Secrets within 7 days. For any other deletion request, message @shnoalsalfa_bh; we respond within 7 days.
